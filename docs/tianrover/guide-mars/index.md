# Mars Rover 使用指引

::: warning 车型说明
本页面用于 Mars Rover（火星车）。涉及电源、电池、急停和运动控制的操作，请严格按照实车标识和安全要求执行。
:::

## 1. 接口说明

以下为 Mars Rover 接口及控制部件示意图，各编号对应下表说明。

![Mars Rover 接口与控制部件示意图](/images/mars-rover-interfaces.png)

1. **TFT 显示屏**：显示电池电量和功率。
2. **总电源开关**：长按总电源，听到滴声提示音后松手，整车供电；点按显示当前电量和功率。
3. **急停开关**：按下后整车执行电机断电，但不影响上位机供电。
4. **USB 接口**：USB 3.0 接口，直接连接上位机。
5. **以太网接口**：连接车载路由器 LAN 口。
6. **HDMI 接口**：输出上位机运行画面。
7. **外部供电接口**：为外接搭载设备提供 24 V / 3 A 电源输出。
8. **充电指示灯**：绿色呼吸灯表示正在充电；蓝色闪烁表示充电器检查阶段；红色闪烁表示电源故障，需要检查。
9. **充电接口**：使用 43.8 V / 10 A 磷酸铁锂电池充电器充电，严禁反接或短接。


## 2. 开机与关机

### 开机

1. 确认急停开关处于释放状态。
2. 长按总电源开关，听到提示音后松手。
3. TFT 显示屏点亮，表示整车已完成上电。

![Mars Rover 开关机模块：左侧为 TFT 显示屏，右侧为总电源开关](/images/mars-power-panel.png)

### 关机

长按总电源开关，听到关机提示音后松手即可关机，不需要单独关闭上位机。建议车辆停止运动后再执行关机。

## 3. 电池与充电

Mars Rover 使用 **36 V / 45 Ah 磷酸铁锂电池**。

### 充电步骤

1. 将车辆停放在稳定、通风且远离可燃物的位置。
2. 按下急停开关，防止充电过程中车辆启动。
3. 连接 **43.8 V / 10 A 磷酸铁锂电池充电器**。
4. 根据充电指示灯判断充电状态。

![Mars Rover 充电模块：左侧为充电指示灯，右侧为充电接口](/images/mars-charge-panel.png)

车辆可以边充电边使用，但充电时必须按下急停开关，避免驱动电机意外启动。充电接口严禁反接或短接。

### 充电指示灯

- 绿色呼吸灯：正在充电。
- 蓝色闪烁：充电器检查阶段。
- 红色闪烁：电源故障，需要检查。

TFT 显示屏会进行低电量提示；电量过低时，车辆会自动关机。

## 4. 急停开关

按下急停开关后，只有驱动电机部分断电，上位机、TFT 显示屏和路由器继续供电。车辆失控时，应立即按下急停开关。

急停开关采用旋转方式释放。解除急停后不需要重新上电，但重新运动前应确认车辆周围无人员和障碍物。

## 6. 无线遥控器

Mars Rover 使用**云卓 G20**遥控器。遥控器不需要单独打开接收机，长按序号 11 的电源按键即可开机或关机；车辆上电后会自动完成配对。

### 遥控器正面

![云卓 G20 遥控器正面视图](/images/yunzhuo-g20-front.png)

### 遥控器顶部

![云卓 G20 遥控器顶部视图](/images/yunzhuo-g20-top.png)

### 模式切换

使用遥控器正面的**序号 2 三档开关**切换控制模式：

- 开关处于最下方：**遥控模式**。
- 开关处于中间或最上方：**ROS 模式**。

### 摇杆控制

在遥控模式下，使用左右摇杆控制车辆运动：

- **左侧摇杆**：控制前进、后退、左移和右移。
- **右侧摇杆左右方向**：控制车辆自旋。
- **右侧摇杆上下方向**：当前未分配功能。

### 最大速度调节

序号 20 按键用于循环调整车辆最大速度。每按一次切换一个档位，切换到最高档后再次按下将回到最低档。每次整车上电后默认处于一档。

| 档位 | 最大速度 |
|---|---:|
| 一档 | 0.5 m/s |
| 二档 | 1.0 m/s |
| 三档 | 1.8 m/s |

遥控器失联或失灵时，车辆会停止运动。急停开关的优先级高于遥控器，发生异常时应立即按下急停开关。

## 7. 使用前检查

- 急停开关已释放，且车辆周围无人员和障碍物。
- 电池电量充足，TFT 屏幕无低电量提示。
- 遥控器已开机并完成配对，模式开关处于正确位置。
- 电脑已连接 `Tianrover-5G` 网络。
- 充电器已断开，或充电状态下已按下急停开关。
