# 绑定 iCAN 赛事与队伍

绑定将本机裁判的后续正式成绩关联到你的赛事与队伍。请在第一次正式准备发车之前完成，练习成绩不能事后补绑提交。

## 绑定前准备

- 按[运行教程](./run-and-test)打开新裁判界面。
- 保证本机浏览器能访问 [赛事主页](https://race.tianbot.com/e/2026-ican-ai)。
- 准备赛务发放的本届 **6 位许可码**，由大写字母和数字组成。
- 保持车辆静止，当前没有等待发车或计时中的比赛。

若尚未拿到许可码，请联系本届赛务确认参赛队伍与许可。许可码用于确定队伍和授权期限，不要公开分享。

## 1. 在裁判中点击“绑定赛事”

裁判从 `https://race.tianbot.com` 加载可绑定赛事，列表显示赛事名称与网址标识。选择本届 iCAN 赛事，网址标识为：

```text
2026-ican-ai
```

如果只有一个可绑定赛事，会自动选中；仍请核对名称再点击“前往绑定”。用户只选择赛事，不需要选择赛段。

## 2. 列表中没有赛事时

先刷新列表。若需要手动指定，在下拉框选择“手动输入”，填写：

```text
https://race.tianbot.com/e/2026-ican-ai
```

也可填写网址标识 `2026-ican-ai`。点击“核验赛事”，核验成功后确认返回的赛事名称，再前往绑定。

网络失败、赛事不可用或核验失败时，先解决原因；不要选择其他赛事凑合绑定。不同赛事的许可码不能用于本届赛事。

## 3. 在浏览器输入许可码并核对队伍

点击前往绑定后，裁判自动读取本机 ROS2GO 的设备身份并打开浏览器。请在这台运行裁判的电脑上完成流程：

1. 输入赛务发放的 6 位许可码。
2. 核验许可，等待页面显示所属队伍。
3. 仔细核对赛事、队伍名称。
4. 确认无误后完成绑定。
5. 回到裁判，等待显示绑定完成。

无需手工输入 SN、设备 ID 或 Token，也不需要复制浏览器地址中的凭证。队伍名称来自平台许可记录，不能通过填写本机名称改变归属。

如果页面显示的是其他队伍，先停止确认并联系赛务核对许可码。

## 4. 在裁判里确认绑定已生效

应看到平台返回的赛事与队伍名称，事件记录提示“赛事绑定完成”。已有绑定时，绑定按钮会按当前状态更新，不需要每次启动裁判都重复绑定。

浏览器完成确认后若裁判没有同步成功，请先检查裁判事件记录。不要因为网页显示成功就立即开始正式跑圈；以裁判显示有效绑定为准。

绑定只影响以后开始的比赛。已经未绑定开始的一轮，即使后来绑定成功，仍然不能提交。

## 5. 正式发车前会再核验

裁判在绑定完成后、约每 30 秒及准备发车时检查平台授权。正式发车前还会检查当前设备身份与凭证是否一致。

| 提示或情况 | 建议操作 |
| --- | --- |
| 正确赛事、队伍，绑定有效 | 可以继续检查环境并准备正式发车 |
| “绑定暂时无法确认” | 恢复网络，等待核验；不要将此时开始的本地练习当作可提交成绩 |
| 已撤销、过期或凭证失效 | 联系赛务处理，再重新完成绑定 |
| 本机设备身份读取失败 | 检查 ROS2GO 镜像和裁判日志，见[常见问题](./troubleshooting#binding) |

网络异常不会自动删除本地凭证，但该轮能否上报取决于发车前核验。准备发车后请查看事件记录，确认没有“本轮仅本地练习，不能事后补绑提交”。

## 换机、错绑或授权撤销

一份队伍许可可以绑定的设备数由赛务设定。达到上限时，联系管理员处理旧设备绑定或容量，不要为绕过上限改设备身份。

错绑、更换设备、旧授权被撤销时联系赛务。参赛者不能自行在客户端撤销绑定；管理员允许重新绑定后，仍需重新走浏览器流程，旧凭证不会因此自动恢复。

不要删除本地绑定文件尝试解除服务器授权，也不要把一台电脑的绑定文件复制到另一台电脑。准备发车及提交时都会检查本机身份。

绑定完成后，返回[准备发车](./run-and-test#arm-race)，开始正式尝试。
