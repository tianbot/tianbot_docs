# 常见问题

## 软件里没有可用串口

先确认Micro-USB线支持数据传输，再检查Mini已上电、接口插稳。通过拔插比较lsusb与设备节点，区分“USB设备没识别”和“设备已识别但软件没列出”。

```bash
lsusb
```

```bash
ls /dev/ttyUSB* /dev/ttyACM* 2>/dev/null
```

仅能充电、没有新USB设备时，优先换数据线或USB口；已经出现串口时，再检查软件版本、串口权限与占用。

## 串口打开失败

关闭其他串口工具，检查设备权限：

```bash
ls -l /dev/ttyUSB0
id -nG
```

将ttyUSB0换成实际设备。若设备所属组为dialout，而当前用户不在该组，可加入后重新登录：

```bash
sudo usermod -aG dialout "$USER"
```

不必通过长期使用root运行整个软件来解决串口权限。

## 打开了串口，但读取没有返回

确认选中了当前Mini对应的端口，并使用配套波特率与固件。关闭串口、重新连接后先读取，确认返回有效再保存新参数。无法读回时不要把界面中的内容当作已保存配置。

## 保存后Mini没有连上电脑

核对路由器是否支持2.4GHz、名称和密码是否正确，以及RMIP是否仍是电脑当前IP。点击“本机IP”后也要检查网卡，尤其是电脑同时启用了VPN、虚拟网卡或有线与无线网络时。

然后按[Mini进入集群模式](../tianbot_mini/swarm/guide/network-setup.md)的步骤操作，并启动底盘驱动检查odom；只看指示灯不能确认整条链路都已经接通。

## 能否用Studio直接运行编队

当前手册介绍的是设备网络配置。三车编队、动捕和轨迹使用[ABC Swarm](../abc_swarm/index.md)的实验入口；按相应实验页的launch命令运行。
