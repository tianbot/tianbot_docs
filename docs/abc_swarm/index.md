# ABC Swarm

ABC Swarm是面向机器人教学的集群实验软件。通过配置机器人名单、定位来源和任务，让多台机器人完成点镇定、队形跟随与轨迹运动，观察每一步的目标、反馈和速度指令。

当前动捕实验面向**三台Tianbot Mini、ROS 1 Noetic和NOKOV/VRPN定位**。先跑通单车连接，再接入三台设备，就可以逐项学习下面的实验。

![三车三角形路径示意](/abc_swarm/triangle.svg)

## 可以做哪些实验

| 实验 | 学习内容 | 操作入口 |
| --- | --- | --- |
| 点镇定 | 从当前位置走到目标位置，再对齐方向 | [点镇定与自动入位](./point-stabilization.md) |
| 三角形跟随 | 02、03分别保持在01的左后方和右后方 | [三角形跟随](./triangle-following.md) |
| 蛇形跟随 | 01带02，02带03 | [蛇形跟随](./snake-following.md) |
| 三车画圆 | 三台车先到同一个圆上的三个起点，再沿圆运动 | [三车画圆](./circle.md) |
| 三车走三角形 | 各占一个顶点，每次走一条边，到齐后转向 | [三车沿三角形运动](./triangle.md) |

点镇定是后续实验的基础。三角形和蛇形跟随默认先自动入位，再交给遥控或头车路径；圆形和三角形轨迹也会先到各自起点。

## 第一次使用

按下面的顺序准备，完成一项再继续下一项：

1. [安装软件](./installation.md)：确认使用新实验对应的功能包版本。
2. [准备Mini集群](./mini.md)：配网、命名、进入集群模式，确认底盘驱动收到反馈。
3. [接入NOKOV动捕](./mocap.md)：检查三台车的刚体和坐标系，启动公共后台。
4. 从[三角形跟随](./triangle-following.md)或[蛇形跟随](./snake-following.md)开始，再体验两项轨迹实验。

::: warning 启动前留出活动空间
实验在所需反馈有效后自动执行入位，不需要调用启用服务。同一组车一次只运行一个实验。普通点镇定和路径跟踪不感知墙、桌或人员；ORCA只在明确启用的入位阶段处理登记车辆之间的避让。
:::

## 支持范围

| 内容 | 当前说明 |
| --- | --- |
| 动捕真车实验 | 三台Mini，三角/蛇形跟随、点镇定、圆形和三角形轨迹 |
| 定位 | VRPN位姿和TF，公共参考系为world |
| 可视化 | RViz显示目标、控制位姿和计划路径 |
| 交付配置 | 可用离线生成器把实验单生成launch，见[用AI配置实验](./ai-experiments.md) |
| 原视频课程 | 继续使用原有命令和仿真内容，见[原视频课程与仿真](./legacy-course.md) |
| TOM06S、TT等新动捕实验 | 后续适配方向，当前三Mini入口不能只换设备名直接使用 |

Mini是差速车，TOM06S是全向车，TT还涉及高度和起降。它们需要匹配各自运动模型，不能因为都使用Twist消息就直接互换。

## 从哪里查问题

- 配网或按键操作不清楚：回到[Mini配网与集群模式](../tianbot_mini/swarm/guide/network-setup.md)。
